# Три дизайна на одной странице GitHub Pages

В этой версии находятся три принципиально разных визуальных решения. Они переключаются кнопками `1`, `2`, `3` без перезагрузки страницы:

- `1 — Noir Gold`: люксовый чёрно-золотой split-screen с мягкой анимацией;
- `2 — Swiss Grid`: строгая белая модульная сетка с острыми углами;
- `3 — Retro Pop`: яркий постерный дизайн с коллажем и бегущей строкой.

Выбранный вариант сохраняется в браузере и добавляется в адрес страницы:

```text
?design=1
?design=2
?design=3
```

Поэтому один и тот же GitHub Pages можно показывать разными прямыми ссылками. API и последовательность создания записи общие для всех дизайнов.

Загрузите в корень репозитория:

- `index.html`;
- папку `assets` вместе с тремя изображениями внутри;
- существующий `cancel.html`, который используется для управления записью.

Структура должна выглядеть так:

```text
/
├── index.html
├── cancel.html
└── assets/
    ├── interior.jpg
    ├── storefront.jpg
    └── entrance.jpg
```

Имена файлов и регистр букв менять не нужно. На GitHub Pages `assets` и `Assets` считаются разными папками.

## Проверка зависимостей

- Изображения подключены относительными путями из этого же репозитория.
- SVG-изображения и SVG-фавикон не используются.
- Внешние шрифты, библиотеки, CDN и сторонние ссылки на изображения не используются.
- CSS и JavaScript находятся внутри `index.html`.
- Единственная обязательная внешняя зависимость — опубликованный Google Apps Script API, через который загружается расписание и создаётся запись.
- Если API временно недоступен, сама страница продолжит открываться и покажет понятное сообщение об ошибке.
